# gip-navigational-guide-robot
First-time visitors may not know where Garage facilities are located, what each area is used for, or which machines require additional training. 
The team will develop a mobile guide robot that lets visitors select an approved destination and navigate there using a mapped representation of the makerspace. The robot will respond safely to obstacles, provide short explanations at selected locations and return to a designated home position after a guide request. The project also creates a reusable robotics platform for future visitor-facing applications.
